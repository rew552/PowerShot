# PowerShot v3.2 — レスポンシブ・デバイス非依存 UI リファクタリング計画（実装版）

> **Plan ID:** 1778361768702-quiet-planet  
> **承認元:** 1778360958600-swift-mountain  
> **調整点:** タッチ対応（タッチ最小サイズ・ボタン拡大）は除外。デスクトップ（マウス/キーボード）操作用に最適化。

---

## フェーズ1: WPF XAML レイアウト

### 1.1 MainWindow.xaml
- `Width="1100" Height="650"` を削除。`MinWidth="720" MinHeight="480"` に変更。
- ウィンドウ初期サイズは `SystemParameters.WorkArea` の90%以内にコードで制限（C#）。
- 右カラム（TabControl）に `MinWidth="260"` を設定し、極端な縮小を防止。
- フォームラベル列を `SharedSizeGroup` 化し、固定 `Width="70"` を削除。
- `FontSize` を `Window.Resources` で一元管理（`FontSizeBase=13`, `FontSizeSmall=12`, `FontSizeLarge=14`）。
- GridView列幅を `Width="Auto"` に変更。C#側で `MaxWidth` 制約を追加。
- プレビュー用 `Viewbox` の親Borderに `MaxWidth`/`MaxHeight` バインディングを追加し、右カラムが押し出されないようにする。

### 1.2 SettingsWindow.xaml
- `Width="500" Height="360"` を削除。`MinWidth="360" MinHeight="280"` を設定し、リサイズを許可。
- ラベル列を `SharedSizeGroup` 化、`Width="120"` を削除。
- フッターボタンの固定 `Width="80"` を削除。`MinWidth="72"` + コンテンツ駆動に変更。

### 1.3 PreviewWindow.xaml
- `Width="800" Height="600"` を削除。`MinWidth="320" MinHeight="240"` を設定。
- 画像サイズに応じた動的サイズ調整をC#で実施（PreviewLauncher.Show）。
- 画面超過時はスクロール可能に（ScrollViewerでViewbox/Imageをラップ）。

---

## フェーズ2: レンダリングエンジン

### 2.1 OverlayRenderer.cs
- 固定値 `FontSize=16f`, `Padding=12f` を廃止。
- 画像短辺に対する比率ベースに変更：`FontSizeRatio=0.022f`, `PaddingRatio=0.015f`。
- Min/Max クランプ：`MinFontSize=10`, `MaxFontSize=56`, `MinPadding=6`, `MaxPadding=32`。
- `GetPosition` メソッドに `padding` パラメータを追加（リフレクション用テスト互換のためオーバーロード可）。

### 2.2 CropController.cs
- 固定 `EdgeMargin=8.0`（ビットマップピクセル）を維持するが、画面DIP換算で12DIP相当になるよう、Canvasの表示倍率（`ActualWidth / Width`）で除算して論理ピクセルに変換。
- これにより、4K画像を小さく表示した場合でも枠の掴みやすさ（画面上の物理サイズ）を保持。

## フェーズ3: HTMLビューア（viewer_template.html）

### 3.1 レスポンシブレイアウト
- サイドバー：`width: 250px` → `minmax(200px, 18vw)`（CSS Grid）。
- ギャラリー：Flexbox固定幅から `grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))` に変更。
- サムネイル：固定高さ `135px` → `aspect-ratio: 16/9` + `width: 100%`。
- メディアクエリ：
  - `max-width: 768px` でサイドバー非表示、1列レイアウト。
  - `min-width: 1920px` で `html { font-size: 16px; }`。
- ライトボックスボタンはマウス操作前提のまま（タッチ拡大なし）。
